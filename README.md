# Portafolio

Página de portafolio personal de una desarrollador web junior. Presenta una breve descripción personal, las habilidades y herramientas que usa, proyectos destacados con enlaces a su demo y a su repositorio, y los datos de contacto.

El diseño es responsivo y se adapta a computadora, tableta y celular.

## Tecnologías y técnicas

- HTML5 semántico (`header`, `main`, `section`, `footer`, listas, encabezados `h1`–`h3`)
- CSS3 con metodología BEM
- Flexbox y CSS Grid para la maquetación
- Media queries (puntos de quiebre en 1023px y 767px)
- Degradados lineales y radiales (subrayado de los enlaces, capa oscura sobre las imágenes y luces de fondo)
- Estados `:hover` en enlaces e íconos
- Fuentes Open Sans y Archivo Black
- normalize.css
